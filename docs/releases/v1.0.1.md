# Settlement Lab v1.0.1

A documentation release. The engine and API code are the same as v1.0.0 (`addb86d`): no main Java
source, build or CI file changed. One test changed: `RunPrivacyLogTest` no longer leaks its DEBUG log
level into later test classes, which had made Linux CI fail or stall depending on the order the test
classes ran in. This release exists so that a download carries a licence, which v1.0.0's tag did not.

## What changed since v1.0.0

- **Licence:** the project is open source under the MIT licence (`LICENSE`, "Copyright (c) 2026
  Siddhesh Fulawade"). v1.0.0 had no licence file.
- **README:** a new top section: a short summary, the six invariants that every run checks, a short
  results table with its conditions and what it does not prove, and a one-command run.
- **Diagrams:** the three explainer diagrams (a transfer's path; ordered locking and compare-and-set;
  the circuit breaker and the outbox during an outage) were redrawn as step-by-step animations,
  reviewed against the code. They stop when the system asks for reduced motion. The README also gains
  a Mermaid module diagram.
- **Decisions:** the full decision log moved to `docs/DECISIONS.md`; the README keeps a short summary.
  No decision changed. "16-core" now reads "16 logical processors", which is what the runner counts.

## Results

Unchanged. The committed run is still commit `3eb119a`: one run on a cloud container (Intel Xeon @
2.10 GHz, 4 cores, Linux amd64, JDK 21.0.13), 12 cells, all six invariants passed in every cell. It
is a single run on 4 cores with no repeat, so the directions mean more than the exact ratios. No
committed result was re-measured; the README adds one timing of the one-command run (10,000
transfers, 45 s on a laptop).

## How to run

Nothing is hosted. Clone the repository or download this release, then follow "Run it with one
command" and "Run it locally" in the README. Needs JDK 21 or newer (25 recommended).

## Known issues (unchanged from v1.0.0)

- The database results command fails with `ClassNotFoundException` (README, Database results); there
  are no PostgreSQL numbers yet.
- Low-severity items not fixed: 415 and 405 answers repeat the visitor's Content-Type or method; a
  malformed request line logs one Tomcat INFO line per window; the `settlement.runs.preview-origin`
  check accepts a port above 65535; the test `MultipartNotParsedHttpTest` leaves a Tomcat temporary
  folder behind.
- Also not fixed (`docs/learn/fix-02-hardening.md`): an ended run frees its slot before its engine
  has closed (L-4); Tomcat's own 400 page and the framework's TRACE and unsupported-method bodies
  (L-7); a client sending one byte every 4 s keeps a connection open.
- The LLD PDF was not rebuilt and still shows the v1.0.0 versions of the diagrams.
